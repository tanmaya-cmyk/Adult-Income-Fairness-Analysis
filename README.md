# Adult-Income-Fairness-Analysis
About

This project uses the Adult Census Income dataset to compare two machine learning models and check how their predictions differ for males and females.

What I Did

Handled missing values in the dataset.

Converted categorical data into numbers.

Scaled numerical data.

Compared Linear Regression and Logistic Regression.

Checked model results for males and females.

Studied prediction errors and fairness measures at different thresholds.

Dataset

The dataset is from the UCI Adult Census Income dataset.

The target values are:

1 – Income above $50K

0 – Income of $50K or less

Files

Adult_Income_Fairness_Analysis.ipynb – Contains the code and calculations.

Adult_Income_Computations_Report_.pdf – Contains the results and calculations.

How to Run

Open the notebook in Google Colab or Jupyter Notebook.

Run all the cells from top to bottom.

Make sure you have an internet connection to load the dataset.

Tools Used

Python, Pandas, NumPy, Scikit-learn, Matplotlib and Jupyter Notebook.

Aim

The aim of this project is to compare model predictions and study fairness in the results for different groups.
